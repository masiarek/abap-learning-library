# Foundations

The ideas you meet in your first week of ABAP and keep using forever. Each page is one idea, with a program you can run beside it.

| Lesson | Level | What it teaches |
|---|---|---|
| [How long is a string?](how_long_is_a_string/README.md) | 201 | `strlen( )` counts UTF-16 code units, `xstrlen( )` counts bytes, and nothing built in counts what a reader would call a character |

The row is written by hand; the lesson's output is not. See [CONTRIBUTING.md](../CONTRIBUTING.md) for the shape of a page and how its recorded output gets there.

A page belongs on this shelf once its program has been **run** in a named system and its transcript recorded. Until then the same material lives as a syntax-checked page under [Keywords](../02_Keywords/README.md) or [Topics](../03_Topics/README.md) — which is why those shelves are larger than this one, and why nothing on them shows output.
